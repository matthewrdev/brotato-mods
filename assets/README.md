# Artwork

`final/` contains the canonical Djinn, Shaman, Magic Lamp, Monkey's Paw, and
Wish item art. Runtime copies live in
`root/mods-unpacked/Careful-Wish/assets/`.

Character portraits are combined icons. In-run characters use separate face
and hat layers over Brotato's native body. The Paw has 3/2/1/0-charge states.

All custom artwork was AI-generated. Human cleanup, redraws, and replacements
are very welcome—please contribute through the
[public repository](https://github.com/matthewrdev/brotato-mods).

Keep only approved masters here; do not retain generation drafts.
