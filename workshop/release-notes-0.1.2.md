# Wish 0.1.2

- Fix startup crashes on Brotato 1.2 by using the new content getters.
- Register Wish characters and items in an item set so they survive cache and
  shop-pool rebuilds, including changes in the Item Sets menu.
- Fix Wish for Corruption to use the DLC lookup introduced in Brotato 1.2.
- Preserve existing character and item IDs for saved games.

Requires Abyssal Terrors. Targets Brotato 1.2.0.0 with ModLoader 6.3.0.
Fully quit and restart Brotato after updating.
